2. MODULE & FUNCTION RESPONSIBILITIES
====================================================================================================

----------------------------------------------------------------------------------------------------
[FRONTEND]
----------------------------------------------------------------------------------------------------
* frontend/config.js:
    - Global window.API_BASE_URL configuration

* frontend/api.js:
    - ApiService.request(endpoint, options)       : Core HTTP fetch wrapper with error handling
    - ApiService.getSummary()                     : GET  /api/data/summary
    - ApiService.listEnergyData()                 : GET  /api/data
    - ApiService.getEnergyData(id)                : GET  /api/data/{id}
    - ApiService.createEnergyData(data)           : POST /api/data
    - ApiService.updateEnergyData(id, data)       : PUT  /api/data/{id}
    - ApiService.deleteEnergyData(id)             : DELETE /api/data/{id}
    - ApiService.sendChatMessage(msg, convId)     : POST /api/chat
    - ApiService.listConversations()              : GET  /api/conversations
    - ApiService.getConversation(id)              : GET  /api/conversations/{id}
    - ApiService.deleteConversation(id)           : DELETE /api/conversations/{id}

* frontend/app.js:
    - init()                                      : Runs loadSummary(), loadDailyData(), loadConversations()
    - initDarkMode() / toggleDarkModeIcons()      : Manages dark/light theme in localStorage
    - openSidebar() / closeSidebar()              : Toggles conversation history drawer
    - showToast(message, type)                    : Renders floating toast feedback
    - loadSummary() / renderSummary()             : Fetches & renders KPI header cards
    - renderInsights(summary)                     : Builds HTML for 5 insight sections
    - renderChart(records) / updateChartTheme()   : Configures Chart.js line timeseries
    - loadDailyData() / renderDailyTable()        : Fetches & renders CRUD table rows
    - openAddModal() / openEditModal()            : Prepares data input modal dialog
    - exportDailyDataToCsv()                      : Converts cached records into RFC 4180 CSV download
    - appendMessage() / appendTypingIndicator()   : Manages chat bubble UI and loading animation
    - selectConversation() / startNewChat()       : Loads selected thread history or resets UI

----------------------------------------------------------------------------------------------------
[BACKEND - API ROUTERS]
----------------------------------------------------------------------------------------------------
* app/main.py:
    - FastAPI app instance & CORS middleware configuration
    - /health (health_check)                      : Returns server status & environment info
    - / (StaticFiles mount)                       : Serves frontend SPA files

* app/routers/data.py:
    - GET    /api/data/summary                    : Calls EnergyDataService.get_summary()
    - GET    /api/data                            : Calls EnergyDataService.list_energy_data()
    - POST   /api/data                            : Calls EnergyDataService.create_energy_data()
    - GET    /api/data/{id}                       : Calls EnergyDataService.get_energy_data_by_id()
    - PUT    /api/data/{id}                       : Calls EnergyDataService.update_energy_data()
    - DELETE /api/data/{id}                       : Calls EnergyDataService.delete_energy_data()

* app/routers/chat.py:
    - POST   /api/chat                            : Calls AIChatService.process_chat(payload)

* app/routers/conversations.py:
    - GET    /api/conversations                   : Calls ConversationService.list_conversations()
    - POST   /api/conversations                   : Calls ConversationService.create_conversation()
    - GET    /api/conversations/{id}              : Calls ConversationService.get_conversation_by_id()
    - DELETE /api/conversations/{id}              : Calls ConversationService.delete_conversation()

----------------------------------------------------------------------------------------------------
[BACKEND - CORE, DATABASE & ANALYSIS]
----------------------------------------------------------------------------------------------------
* app/core/config.py:
    - Settings (BaseSettings)                     : Loads .env, parses CORS ALLOWED_ORIGINS, PORT, ENV

* app/database/firestore.py:
    - init_firestore()                            : Initializes Firebase credentials (JSON string / file)
    - get_firestore_db()                          : Returns Firestore client instance (or None in mock mode)
    - is_firestore_mock()                         : Checks if operating in offline mock mode

* app/analysis/preprocessor.py:
    - validate_raw_energy_data(df)                : Checks 30-min timestamps, nulls, negative values
    - aggregate_to_daily(df)                      : Sums 48 intervals per day into daily kWh totals
    - process_raw_file(raw_path, output_path)     : End-to-end pipeline from raw CSV to processed daily CSV

* app/analysis/summary.py:
    - generate_energy_summary(daily_df)           : Calculates 10 analytical dimensions:
                                                    1. Period (start, end, duration)
                                                    2. Coverage & complete days count
                                                    3. Overall statistics (sum, mean, median, std)
                                                    4. Extremes (peak day, lowest day)
                                                    5. Monthly breakdown
                                                    6. Weekday vs Weekend pattern
                                                    7. Day-of-week averages
                                                    8. Recent windows (7-day, 30-day averages)
                                                    9. Trend analysis (rolling 7-day, linear slope)
                                                    10. Estimated costs (£)

----------------------------------------------------------------------------------------------------
[BACKEND - SERVICES & BUSINESS LOGIC]
----------------------------------------------------------------------------------------------------
* app/services/data_service.py:
    - FirestoreEnergyRepository:
        - _ensure_initial_dataset_loaded()        : Loads daily_energy.csv into memory mock store
        - get_all()                               : Merges baseline mock records with Firestore stream
        - get_by_id(date_id)                      : Retrieves specific record from Firestore/mock
        - create(data) / update(id, data)         : Writes record to Firestore & local memory store
        - delete(id)                              : Deletes record from Firestore & local memory store
    - EnergyDataService:
        - get_summary()                           : Converts records to DataFrame and calls summary engine
        - list_energy_data() / get_energy_data_by_id() / create_energy_data() / update_energy_data() / delete_energy_data()

* app/services/conversation_service.py:
    - FirestoreConversationRepository:
        - get_all() / get_by_id(conv_id)          : Fetches conversation documents
        - create(data) / update(conv_id, data)    : Stores/updates message threads
        - delete(conv_id)                         : Removes conversation document
    - ConversationService:
        - record_chat_exchange(conv_id, user_msg, ai_reply) : Auto-persists user & assistant messages

* app/services/ai_service.py:
    - AIChatService:
        - _build_system_prompt(summary)           : Constructs anti-hallucination prompt with injected JSON summary
        - process_chat(req)                       : Coordinates summary retrieval, GPT completions, tool calls
        - _fallback_keyword_response(query, summ) : Offline deterministic responder when OpenAI key is missing
    - Function Calling Tools:
        - _tool_get_energy_data_by_date(args)     : Tool 1 - specific date lookup with boundary validation
        - _tool_get_energy_data_by_period(args)   : Tool 2 - date range day-by-day record retrieval
        - _tool_get_energy_statistics(args)       : Tool 3 - deterministic period stats calculation

FLOW 2: DATA MANAGEMENT (CRUD OPERATIONS) & CSV EXPORT
----------------------------------------------------------------------------------------------------

1) CREATE / ADD RECORD:
   User Clicks "+ Add Day" ──► app.js: openAddModal()
   User Submits Form      ──► app.js: dataForm.submit Event
   app.js                 ──► api.js: ApiService.createEnergyData({date, value, memo})
   HTTP POST /api/data    ──► routers/data.py: create_energy_data(payload: EnergyDataCreate)
   routers/data.py        ──► services/data_service.py: EnergyDataService.create_energy_data()
   data_service.py        ──► FirestoreEnergyRepository.create(doc_data)
   Repository             ──► Firestore 'data' collection: db.collection("data").document(date).set(...)
   Repository             ──► Local Mock Store updated
   Response 201 Created   ──► app.js receives success ──► showToast("Record added")
   app.js                 ──► Promise.all([loadDailyData(), loadSummary()]) ──► Table, KPIs, Chart Refreshed

2) UPDATE RECORD:
   User Clicks "Edit"     ──► app.js: openEditModal(record)
   User Submits Form      ──► api.js: ApiService.updateEnergyData(id, {value, memo})
   HTTP PUT /api/data/{id}──► routers/data.py: update_energy_data() ──► EnergyDataService.update_energy_data()
   data_service.py        ──► FirestoreEnergyRepository.update(id, data) ──► Firestore doc updated
   app.js                 ──► showToast("Record updated") ──► loadDailyData() & loadSummary()

3) DELETE RECORD:
   User Clicks "Del"      ──► app.js: handleDeleteRecord(id)
   HTTP DELETE /api/data/ ──► routers/data.py: delete_energy_data() ──► EnergyDataService.delete_energy_data()
   data_service.py        ──► FirestoreEnergyRepository.delete(id) ──► Firestore doc deleted
   app.js                 ──► showToast("Record deleted") ──► loadDailyData() & loadSummary()

4) CSV EXPORT:
   User Clicks "Export"   ──► app.js: exportDailyDataToCsv()
   app.js                 ──► Reads cachedDailyRecords ──► formats CSV (date, consumption_kwh, memo)
   app.js                 ──► Creates Blob (text/csv) ──► triggers browser download (.csv file)

FLOW 4: AI CHAT - FUNCTION CALLING / TOOL USE (SPECIFIC DATE / RANGE / MEMO)
----------------------------------------------------------------------------------------------------

User types: "How much electricity did I use on 2026-08-13?"
       │
       ▼
[frontend/app.js] ──► appendTypingIndicator() ──► ApiService.sendChatMessage()
       │
       ▼ (HTTP POST /api/chat)
[app/routers/chat.py] ──► [app/services/ai_service.py: AIChatService.process_chat()]
       │
       ├─► 1. Builds System Prompt with current summary context
       ├─► 2. Calls OpenAI API with TOOL_DEFINITIONS
       │
       ▼
[OpenAI GPT-4o-mini]
       │
       ├─► Analyzes query: Target date 2026-08-13 is NOT an extreme day in summary
       ├─► Generates Tool Call:
       │   tool_calls = [{
       │       "name": "get_energy_data_by_date",
       │       "arguments": {"date": "2026-08-13"}
       │   }]
       │
       ▼
[app/services/ai_service.py]
       │
       ├─► 3. Catches tool_call ──► routes to TOOL_EXECUTORS["get_energy_data_by_date"]
       │
       ├─► 4. _tool_get_energy_data_by_date(args)
       │      ├─► Validates date format: YYYY-MM-DD
       │      ├─► Validates calendar validity
       │      ├─► Checks dataset bounds (2026-03-01 to 2026-08-31)
       │      └─► Calls EnergyDataService.get_energy_data_by_id("2026-08-13")
       │               │
       │               ▼
       │          [Firestore / Repository] ──► Returns {date: "2026-08-13", value: 1.745, memo: null}
       │
       ├─► 5. Formats result as role: "tool" message
       │
       ├─► 6. Sends SECOND request to OpenAI API:
       │      messages = [..., Assistant(tool_calls), ToolMessage(result: {"consumption_kwh": 1.745})]
       │
       ▼
[OpenAI GPT-4o-mini]
       │
       └─► Synthesizes final plain-text answer based on verified tool output:
           "Your electricity consumption on 2026-08-13 was 1.745 kWh."
               │
               ▼
[app/services/ai_service.py]
       ├─► 7. ConversationService.record_chat_exchange(...)
       └─► 8. Returns ChatResponse JSON
               │
               ▼
[frontend/app.js]
       ├─► removeTypingIndicator()
       └─► appendMessage("assistant", "Your electricity consumption on 2026-08-13 was 1.745 kWh.")

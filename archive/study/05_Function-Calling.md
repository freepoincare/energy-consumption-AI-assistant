# Function Calling

`OpenAI().chat.completion.create(model=, messages=, tools=, tool_choice=, temperature=, max_tokens)`

OpenAI API에서 `tools`는 거대언어모델(LLM)이 필요할 때 직접 실행할 수 있는 '외부 도구(함수)'를 정의해 주는 파라미터입니다. 이 기능을 함수 호출(Function Calling)이라고 부릅니다.

LLM은 본래 학습된 데이터로만 답변하기 때문에 실시간 날씨, 최신 주가, 회사 데이터베이스 검색 같은 작업을 수행할 수 없습니다. 

이때 개발자가 tools에 "이런 함수들을 쓸 수 있어"라고 규칙을 정의해 주면, 모델이 판단하여 "지금 답변하려면 이 함수를 이런 매개변수(Arguments)로 실행해야 해"라고 개발자에게 요청합니다.

## 📜 동작하는 3단계 과정

   1. 사용자 요청: "오늘 서울 날씨 어때?"라고 물어봅니다.
   2. 모델의 판단: AI는 스스로 날씨를 알 수 없으므로, 개발자가 tools로 넘겨준 get_current_weather라는 함수의 이름과 인자(location="Seoul")를 JSON 형태로 출력(반환)합니다.
   3. 함수 실행: 개발자의 서버에서 실제로 날씨 API를 호출해 결과를 얻은 뒤, 그 값을 다시 AI에게 전달하면 AI가 최종적으로 자연스러운 답변을 완성합니다.

## 💻 tools 구조 예시

tools 파라미터에는 보통 다음과 같이 함수(type: "function")의 이름과 설명, 그리고 필요한 매개변수 구조를 정의하여 배열로 전달합니다.

```python
tools = [
    {
        "type": "function",
        "function": {
            "name": "get_current_weather",
            "description": "지정된 지역의 현재 날씨를 가져옵니다.",
            "parameters": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "도시나 지역 이름 (예: 서울, 토쿄)"
                    },
                    "unit": {
                        "type": "string", 
                        "enum": ["celsius", "fahrenheit"]
                    }
                },
                "required": ["location"]
            }
        }
    }
]
```

## 💡 주요 장점

* 실시간 데이터 연동: 최신 정보나 외부 API 데이터를 가져와 답변할 수 있습니다.
* 정확한 액션 수행: 이메일 보내기, 데이터베이스에 레코드 추가하기 등의 동작을 AI가 판단해서 실행하게 할 수 있습니다.
* 구조화된 출력 구조: AI가 임의의 텍스트가 아닌, 정확히 정의된 JSON 규격으로 답변하도록 강제할 수 있습니다.

## 병렬 함수 호출(Parallel Function Calling)

OpenAI의 Tool Calling(함수 호출) 기능은 한 번에 여러 개의 함수(tools)를 동시에 선택하고 호출할 수 있습니다. 이를 병렬 함수 호출(Parallel Function Calling)이라고 합니다.
모델이 여러 개의 함수를 선택하는 방식과 제어 방법은 다음과 같습니다.

### 1. 기본 작동 방식: 병렬 함수 호출 (Parallel Function Calling)

tool_choice="auto"(기본값)로 설정되어 있을 때, 모델은 사용자의 질문을 해결하기 위해 필요하다면 동시에 여러 개의 함수를 선택해 배열 형태로 반환합니다.

* 예시 상황: 사용자가 "서울 날씨랑 도쿄 날씨 알려줘"라고 요청한 경우
* 모델의 반응: get_weather라는 함수가 등록되어 있다면, 모델은 이 함수를 각각 '서울'과 '도쿄' 파라미터를 넣어 총 2번 호출하도록 결정합니다. 하나의 답변(choices[0].message.tool_calls) 안에 2개의 함수 호출 정보가 동시에 담겨 오게 됩니다.

## 2. tool_choice 옵션을 통한 제어 방법

만약 무조건 1개만 호출하게 하거나, 호출을 강제하고 싶다면 tool_choice 파라미터를 다음과 같이 조절할 수 있습니다.

* `tool_choice="auto"` (기본값): 모델이 판단하여 호출하지 않거나, 1개를 호출하거나, 여러 개를 동시에 호출할 수 있습니다.
* `tool_choice="required"`: 모델이 무조건 하나 이상의 tool을 선택하도록 강제합니다. (이 역시 필요하면 여러 개를 호출할 수 있습니다.)
* `tool_choice={"type": "function", "function": {"name": "my_function"}}`: 모델에게 오직 지정한 이 함수 1개만 강제로 호출하도록 제한합니다. 이때는 다른 함수나 여러 개의 함수를 선택할 수 없습니다.
* `tool_choice="none"`: 함수를 전혀 호출하지 않고 일반 텍스트 답변만 생성합니다.

## OpenAI 모델의 도구 선택 원리

이해하신 내용이 맞습니다! 모델이 마치 스스로 의지(판단력)를 가지고 필요한 도구를 선택하는 것처럼 작동합니다.
조금 더 정확히 표현하자면, 이는 인간과 같은 자아나 의지라기보다는 사용자의 질문(맥락)을 분석하여 어떤 함수를, 어떤 매개변수(Arguments)로 호출해야 할지 스스로 결정하는 '추론 능력'에 가깝습니다.
이 과정은 다음과 같은 원리로 작동합니다.

### 🤖 모델이 함수를 "선택"하는 원리

   1. 설명문(Description) 분석: 개발자가 tools 파라미터에 함수 이름뿐만 아니라 "이 함수는 무슨 역할을 하는지", "각 파라미터는 무엇을 의미하는지" 적어둔 설명문을 모델이 먼저 읽고 이해합니다.
   2. 의도 파악 (Intent Detection): 사용자의 질문(Context)을 분석하여, 현재 이 질문을 해결하는 데 필요한 데이터나 기능이 무엇인지 파악합니다.
   3. 매칭 및 매개변수 추출: 질문의 내용과 함수의 설명을 비교하여 가장 적절한 함수를 고르고, 질문 속에서 함수에 필요한 값(예: 도시 이름, 날짜 등)을 찾아내어 JSON 형태로 알아서 포맷팅합니다.

### 💡 모델의 '의지'를 체감할 수 있는 예시
만약 아래와 같이 2개의 함수를 등록했다고 가정해 보겠습니다.

* get_current_weather(location): 특정 지역의 날씨를 조회하는 함수
* convert_currency(amount, from, to): 환율을 계산하는 함수

사용자가 질문을 어떻게 하느냐에 따라 모델은 다음과 같이 다르게 행동합니다.

* "지금 뉴욕 비 와?" ➔ 모델이 판단하여 get_current_weather(location="New York") 1개만 선택합니다.
* "100달러를 원화로 바꾸면 얼마야? 그리고 서울 날씨도 알려줘." ➔ 모델이 판단하여 convert_currency와 get_current_weather 2개를 동시에(병렬로) 선택합니다.
* "오늘 기분이 너무 좋아!" ➔ 함수가 필요 없다고 판단하여, 함수를 호출하지 않고 일반 텍스트로 대답합니다.

개발자가 일일이 "이 키워드가 들어오면 이 함수를 실행해"라고 코딩(if-else)할 필요 없이, 모델이 문맥을 보고 알아서 판단(의지적 선택)하기 때문에 에이전트(Agent)형 서비스를 만들 때 매우 강력한 기능입니다.

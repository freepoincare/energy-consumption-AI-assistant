# CRUD

CRUD는 소프트웨어가 데이터베이스나 데이터 저장소를 다룰 때 수행하는 가장 기본적인 4가지 컴퓨터 기능인 Create(생성), Read(읽기), Update(수정), Delete(삭제)의 앞 글자를 딴 줄임말입니다.

## 💡 본문 문맥에서의 CRUD 매칭

* C (Create - 생성): 본문의 '데이터 추가'에 해당합니다. 새로운 날짜, 값, 메모(date, value, memo)를 시스템에 처음 입력하는 동작입니다.
* R (Read - 읽기): 본문의 '출력/화면: 데이터 목록 갱신'에 해당합니다. 저장되어 있는 데이터들을 불러와서 화면에 보여주는 동작입니다.
* U (Update - 수정): 본문의 '데이터 수정'에 해당합니다. 이미 존재하는 데이터의 값이나 메모 내용을 고치는 동작입니다.
* D (Delete - 삭제): 본문의 '데이터 삭제'에 해당합니다. 필요 없는 데이터를 지우는 동작입니다.

즉, 해당 문서는 프로그램이 처리해야 할 핵심 기능으로 "데이터를 넣고(C), 보고(R), 고치고(U), 지우는(D) 전체적인 데이터 관리 기능"을 정의하고 있는 것입니다.

현재 어떤 프로그램이나 서비스(예: 가계부, 일정 관리 앱 등)를 설계하고 계시거나 공부 중이신가요? 구현하려는 프로젝트의 종류를 알려주시면 이 CRUD 기능이 어떻게 코드로 연결되는지 더 구체적으로 설명해 드릴 수 있습니다.

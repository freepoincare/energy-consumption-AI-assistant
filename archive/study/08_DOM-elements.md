# DOM elements

`api.js`에는 없지만, `app.js` 코드의 상단에 보면 `// ─── DOM Elements ───`라는 주석과 함께 변수들이 쭉 나열되어 있죠?

이 **DOM Elements(DOM 요소)**가 무엇인지 아주 쉽게 설명해 드릴게요.

---

### 1. DOM이란 무엇인가요?

**DOM**은 **D**ocument **O**bject **M**odel의 약자입니다.
*   **Document:** 우리가 만든 HTML 파일입니다.
*   **Object:** 자바스크립트가 다룰 수 있는 '물건(객체)'입니다.
*   **Model:** HTML의 구조를 나무(Tree) 모양으로 본떠 만든 모델입니다.

쉽게 말해, **HTML이라는 텍스트 문서를 자바스크립트가 읽고 쓸 수 있도록 브라우저가 변환해 놓은 상태**를 말합니다.

### 2. DOM Elements는 왜 필요한가요?

자바스크립트 파일(`app.js`)은 HTML에 어떤 버튼이 있고 어떤 입력창이 있는지 처음에는 알지 못합니다. 그래서 자바스크립트가 HTML의 특정 부분을 **조종하기 위한 '리모컨'**을 만드는 과정이 필요합니다.

코드에서 이 부분을 보세요:
```javascript
const chatInput = document.getElementById("chat-input");
```
*   **HTML:** `<input id="chat-input" ...>` (글자를 입력하는 칸)
*   **자바스크립트:** `document.getElementById("chat-input")`라는 명령어로 그 칸을 찾아옵니다.
*   **결과:** 이제 `chatInput`이라는 변수는 HTML 입력창을 조종하는 **리모컨(DOM Element)**이 됩니다.

### 3. 우리 코드에서의 예시
`app.js`에 선언된 DOM 요소들이 각각 어떤 역할을 하는지 볼까요?

*   **`chatForm`**: 채팅 전송 버튼을 눌렀을 때 발생하는 이벤트를 감지하는 리모컨.
*   **`metricAvg`**: 서버에서 받아온 '평균 전력 사용량' 수치를 화면의 특정 칸에 글자로 써넣기 위한 리모컨.
*   **`dataModal`**: 팝업창(모달)을 화면에 보이게 하거나 숨기게(display: block/none) 조절하는 리모컨.

### 4. 비유로 이해하기
*   **HTML**: 건물의 **설계도**입니다. (어디에 창문이 있고 문이 있는지 적혀 있음)
*   **DOM**: 설계도대로 지어진 **실제 건물**입니다.
*   **자바스크립트**: 그 건물에서 일하는 **관리인**입니다.
*   **DOM Elements**: 관리인이 들고 다니는 **각 방의 열쇠나 리모컨**입니다. (전등을 켜거나, 문을 열 때 사용)

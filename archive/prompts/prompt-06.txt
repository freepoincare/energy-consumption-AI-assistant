  ### 3. Explanation of Context Injection & Security
  • Context Injection:
  Instead of sending thousands of raw records, the backend dynamically queries Firestore, generates the multi-dimensional statistical summary, and embeds it directly
  into the LLM's system prompt prior to every inference call. This guarantees factually grounded answers at minimum token cost.
  • Why Credentials Remain on the Backend:
  OPENAI_API_KEY is loaded strictly on the server side via environment variables. The client browser only communicates with the backend endpoint POST /api/chat, ensuring
  API keys are never exposed in client bundle code or network inspection tabs.

 ### Root Cause Analysis

  1. Model Context Prompting: While the summary context contained the monthly.monthly_breakdown section with per-month statistics (total_consumption_kwh,
  average_daily_consumption_kwh, and days_count), the strict anti-hallucination rules previously lacked explicit instructions for questions targeting a specific month
  (e.g., "July 2026", "7월"). As a result, the model was defaulting to the high-level overall.average_daily_consumption_kwh.
  2. Offline Fallback Matching: In ai_service.py:498, if a user's question contained both "average" and a month name (such as "What was my average daily consumption
  during July 2026?"), the general "average" keyword matcher triggered first and returned the dataset-wide average across all 184+ days rather than looking up the month
  in monthly_breakdown.

  ### Changes Made

  1. Explicit Prompt Instruction (ai_service.py:319):
      • Added Rule 3 to STRICT ANTI-HALLUCINATION RULES:
      │ "When the user asks about a specific month (e.g. 'July 2026', '2026-07', '7월'), check the monthly.monthly_breakdown section in the summary. If that month exists
      │ in monthly_breakdown, answer with that specific month's metrics (total_consumption_kwh, average_daily_consumption_kwh, days_count) instead of giving the overall
      │ period average."

  2. Specific Month Fallback Handler (ai_service.py:510-558):
      • Implemented month parsing for both English month names (e.g. July, jul), numbers (2026-07), and Korean notations (7월).

      │ "During 2026-07, your average daily electricity consumption was 4.01 kWh/day (total: 124.44 kWh across 31 days)."
